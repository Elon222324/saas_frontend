# OrderDetailsModal

Рефакторенный компонент модального окна деталей заказа, разбитый на модульную структуру для лучшей поддерживаемости.

## Структура

```
OrderDetailsModal/
├── index.jsx                    # Основной компонент
├── utils.js                     # Утилиты для форматирования
├── constants.js                 # Константы и функции для статусов
├── hooks/
│   └── useOrderDetails.js       # Хук для управления состоянием и API
├── components/                  # Компоненты секций
│   ├── Badge.jsx               # Компонент бейджа
│   ├── Row.jsx                 # Компонент строки с лейблом и значением
│   ├── ModalHeader.jsx         # Заголовок модального окна
│   ├── CustomerInfo.jsx        # Информация о клиенте
│   ├── StatusAndPayment.jsx    # Статус и оплата заказа
│   ├── OrderItems.jsx          # Список товаров заказа
│   ├── OrderTotal.jsx          # Итоговая сумма
│   ├── EditOrderForm.jsx       # Форма редактирования заказа
│   ├── NotesSection.jsx        # Секция примечаний
│   ├── EventsSection.jsx       # Секция событий
│   └── ModalFooter.jsx         # Футер модального окна
└── README.md                   # Документация
```

## Компоненты

### Основные компоненты

- **index.jsx** - Главный компонент, который собирает все секции
- **useOrderDetails.js** - Хук для управления состоянием и API вызовами

### Утилиты

- **utils.js** - Функции форматирования (цены, даты, адреса, ошибки)
- **constants.js** - Константы для статусов, лейблов и форматирования событий

### Компоненты секций

- **ModalHeader** - Заголовок с номером заказа и кнопкой закрытия
- **CustomerInfo** - Информация о клиенте (имя, телефон, адрес, дата)
- **StatusAndPayment** - Статус заказа, способ оплаты и элементы управления
- **OrderItems** - Таблица товаров с возможностью изменения количества
- **OrderTotal** - Итоговая сумма с разбивкой
- **EditOrderForm** - Форма для редактирования адреса, способа оплаты и комментария
- **NotesSection** - Добавление примечаний к заказу
- **EventsSection** - История событий заказа

### Вспомогательные компоненты

- **Badge** - Компонент для отображения статусов
- **Row** - Компонент строки с лейблом и значением
- **ModalFooter** - Футер с кнопкой закрытия

## Преимущества рефакторинга

1. **Модульность** - Каждый компонент отвечает за свою функциональность
2. **Переиспользование** - Компоненты можно использовать в других местах
3. **Тестируемость** - Легче писать тесты для отдельных компонентов
4. **Читаемость** - Код стал более понятным и структурированным
5. **Поддерживаемость** - Легче вносить изменения в отдельные части
6. **Разделение ответственности** - Логика API вынесена в отдельный хук

## Использование

```jsx
import OrderDetailsModal from './OrderDetailsModal'

<OrderDetailsModal 
  details={orderDetails}
  onClose={handleClose}
  siteNameForApi={siteName}
  headers={authHeaders}
  refreshOrders={refreshOrdersList}
  reloadDetails={reloadOrderDetails}
/>
```
