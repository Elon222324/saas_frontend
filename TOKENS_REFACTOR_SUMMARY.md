# ✅ Резюме: Централизация управления токенами

## 🎯 Что было сделано

Реализована **централизованная система управления токенами сайтов** с автоматическим кешированием на базе React Query.

✅ **Глобальный QueryClientProvider** - один кеш для всего приложения  
✅ **Рефакторинг SiteSettingsContext** - использует новый хук  
✅ **Упрощены компоненты** - удалены локальные QueryClient  
✅ **Написана документация** - 5 файлов с примерами и диаграммами

## 🐛 Troubleshooting

### Проблема: "Не могу найти хук useSiteToken"
**Решение:** Импортируй так: `import { useSiteToken } from '@/hooks/useSiteToken'`

### Проблема: "Токен не кешируется"
**Решение:** Убедись что QueryClientProvider добавлен в `main.jsx`

### Проблема: "Запросы выполняются без токена"
**Решение:** Добавь `enabled: Boolean(token)` в useQuery

### Проблема: "Ошибка 401 при запросах"
**Решение:** 
1. Проверь что используешь Site Token для site-api (не User Token)
2. Проверь что siteName БЕЗ суффикса `_app`
3. Проверь что User Token актуален в localStorage

### Больше решений
👉 Смотри раздел Troubleshooting в `src/hooks/README.md`
