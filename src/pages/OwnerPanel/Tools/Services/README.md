# Services (Обновление сервисов)

Раздел для управления обновлением Docker образов и перезапуском сервисов администрирования SaaS платформы.

## Структура

```
Services/
├── index.jsx              # Главный компонент страницы
├── api/
│   └── services.js        # API функции для вызова эндпоинтов бекенда
└── components/
    └── ServiceCard.jsx    # Компонент карточки сервиса
```

## Доступные сервисы

### 1. SAAS WEB
- **Эндпоинт**: `POST /api/service/update-saas-web`
- **Функция**: Обновляет образ и перезапускает контейнер saas_web
- **Влияние**: Может привести к временному прерыванию работы административной панели

### 2. Frontend (site-ISR)
- **Эндпоинт**: `POST /api/service/update-frontend`
- **Функция**: Обновляет образ и пересоздает фронтовый site-ISR контейнер
- **Влияние**: Может привести к перезагрузке фронтенда сайтов

### 3. Site Template (site-api)
- **Эндпоинт**: `POST /api/service/update-site-template`
- **Функция**: Обновляет шаблонный образ site-api и перезапускает все сайты
- **Влияние**: **ВНИМАНИЕ**: Все сайты будут перезагружены

### 4. Self Update
- **Эндпоинт**: `POST /api/service/self-update`
- **Функция**: Загружает новый образ docker-update и устанавливает флаг на обновление
- **Влияние**: Подготавливает обновление контейнера администрирования

## Использование

1. Перейдите на страницу **Owner Panel → Tools → Сервисы**
2. Выберите сервис, который нужно обновить
3. Нажмите кнопку **"Обновить"**
4. Дождитесь завершения обновления (статус будет отображен на странице)

## API

### ServiceCard Component

Компонент для отображения карточки сервиса с кнопкой обновления.

**Props:**
- `title` (string): Название сервиса
- `description` (string): Описание сервиса
- `icon` (React Component): Иконка Lucide
- `onUpdate` (function): Функция, вызываемая при нажатии "Обновить"
- `isLoading` (boolean): Показывает ли загрузку

**Особенности:**
- Показывает статус обновления (успех/ошибка)
- Автоматически скрывает сообщение через 5 секунд
- Отключает кнопку во время загрузки

### Service API

```javascript
import { serviceApi } from './api/services'

// Обновить SAAS WEB
await serviceApi.updateSaasWeb()

// Обновить Frontend
await serviceApi.updateFrontend()

// Обновить Site Template
await serviceApi.updateSiteTemplate()

// Self Update
await serviceApi.selfUpdate()
```

Все методы возвращают Promise и выбрасывают ошибку при неудачи.
