# SellerBoard

**SellerBoard** - это интерфейс для просмотра заказов в реальном времени.

Продавец видит поступающие заказы, время забора и может менять статусы.

## Маршрут
```
/board/:siteName
```

## Лейаут
Обёрнут в `SellerLayout` (`src/layouts/SellerLayout.jsx`) - глобальная шапка с "БОРД ЗАКАЗОВ", статусом ONLINE и кнопками навигации (Выбрать сайт, Админка, Выход).

## Структура
```
SellerBoard/
├── index.jsx              # Главная страница (заглушка)
├── api/                   # API запросы
├── hooks/                 # Custom хуки
└── components/            # Компоненты
```
