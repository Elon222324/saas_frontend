## 5. Сценарий: Переключение между сайтами в Orders

```
Time →  0s        2s        4s        6s        8s

User:   Select    Wait      Select    Wait      Select
        Site A    loading   Site B    loading   Site A again
          │                   │                   │
          ▼                   ▼                   ▼
Cache:  Get Token   Use     Get Token   Use     Use cached!
        for A    ┌──────┐   for B    ┌──────┐  (instant)
          │      │ A tk │     │      │ B tk │     │
          ▼      └──────┘     ▼      └──────┘     ▼
API:    POST                POST                 (no request)
        site-token          site-token
        /t4a                /t5b
          │                   │                   │
          ▼                   ▼                   ▼
Orders: Load orders A       Load orders B       Load orders A
        with token A        with token B        with cached token A

Timeline of cache:
┌─────────────────────────────────────────────────────────────┐
│ 0s  2s  4s  6s  8s                                          │
│ │   │   │   │   │                                           │
│ A───A───A───A───A─── (token A cached for 5 min)            │
│         B───B───B─── (token B cached for 5 min)            │
└─────────────────────────────────────────────────────────────┘
```

     │
     ▼

│ useCategories('t4a')                   │
│   │                                    │
│   ▼                                    │
│ useQuery({                             │
│   queryKey: ['categories', token],     │

│     fetch(url, {                       │
│       headers: {                       │

│ })                                     │

     │
     ▼

## 8. Сравнение: До и После рефакторинга

### БЫЛО (старая архитектура)

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│ Products    │  │ Options     │  │ Extras      │
│ Component   │  │ Component   │  │ Component   │
└──────┬──────┘  └──────┬──────┘  └──────┬──────┘
       │                │                │
       │ Each has       │ Each has       │ Each has
       │ local          │ local          │ local
       │ QueryClient    │ QueryClient    │ QueryClient
       ▼                ▼                ▼
┌──────────────────────────────────────────────┐
│ 3x separate QueryClient instances            │
│ 3x separate caches                           │
│ No sharing of data                           │
└──────────────────────────────────────────────┘
       │                │                │
       ▼                ▼                ▼
┌────────────┐   ┌────────────┐   ┌────────────┐
│SiteSettings│   │SiteSettings│   │SiteSettings│
│Context     │   │Context     │   │Context     │
│(duplicate) │   │(duplicate) │   │(duplicate) │
└────────────┘   └────────────┘   └────────────┘
       │                │                │
       │ Each fetches   │ Each fetches   │ Each fetches
       │ token          │ token          │ token
       ▼                ▼                ▼
    FETCH            FETCH            FETCH
    /site-token      /site-token      /site-token
    
❌ 3 запроса на получение одного и того же токена
❌ Нет кеширования между компонентами
❌ Дублирование кода
```

### СТАЛО (новая архитектура)

```
┌──────────────────────────────────────────────┐
│          Global QueryClientProvider          │
│              (in main.jsx)                   │
└──────────────────────────────────────────────┘
                       │
       ┌───────────────┼───────────────┐
       │               │               │
       ▼               ▼               ▼
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│ Products    │  │ Options     │  │ Extras      │
│ Component   │  │ Component   │  │ Component   │
└──────┬──────┘  └──────┬──────┘  └──────┬──────┘
       │               │               │
       └───────────────┼───────────────┘
                       │
                       │ All use:
                       │ useSiteToken('t4a')
                       ▼
┌──────────────────────────────────────────────┐
│         Shared React Query Cache             │
│     ['siteToken', 't4a']: "token..."        │
└──────────────────────────────────────────────┘
                       │
                       │ Only ONE fetch
                       ▼
                    FETCH
                    /site-token
                    
✅ 1 запрос для всех компонентов
✅ Автоматическое кеширование
✅ Единый код в хуке
```

---

**Легенда:**
- `│` `─` `┌` `└` `┐` `┘` - границы блоков
- `▼` `▲` - направление потока данных
- `◄` `►` - важные моменты
- ✅ - преимущества
- ❌ - недостатки
